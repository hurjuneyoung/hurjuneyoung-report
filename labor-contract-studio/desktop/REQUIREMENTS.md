# 구현 계획

React + TypeScript 입력 화면, 순수 도메인 계산, 로컬 전용 Node 서버, Edge 앱 창을 사용한다. 외부 서버 없이 PC에서 실행하며 웹 서비스의 조직 권한·원격 서명은 포함하지 않는다.

1. 시작·계약 목록·사업장 프로필 재사용
2. 8단계 계약 작성, 독립적인 기간/시간/임금 유형
3. 정수 분 일정 계산, 입력 오류와 미승인 법률 규칙 구분
4. 동일 문서 모델을 쓰는 미리보기·A4 PDF
5. 로컬 초안 자동 저장, 충돌 감지, 불변 버전 보관, 복제·변경
6. 다운로드·보관·직접 교부 기록 분리
7. 가상 사례 단위 테스트 및 실제 PDF 검수

법률 규칙은 승인 데이터가 제공되지 않아 미승인 상태로 출하한다. 최종 확정은 차단하고 초안 PDF는 허용한다. 개인정보 실운영 서비스가 아닌 로컬 시제품임을 표시한다.
