# 근로계약서 스튜디오 사용 안내

바탕화면의 **근로계약서 스튜디오** 아이콘을 더블클릭합니다. Edge의 독립 앱 창에서 실행됩니다. 앱 실행 파일은 `contract-app/근로계약서 실행.cmd`입니다. 이 폴더를 이동하면 바로가기 경로도 수정해야 합니다.

## 사용 순서

1. 새 계약 작성 → 사업장·계약 형태·근로자·일정·급여·휴일·보험·특약 입력.
2. 오른쪽 미리보기 확인. 좁은 화면에서는 미리보기 버튼으로 전환.
3. 검토·출력 → 검토용 초안 PDF 다운로드.
4. 작업은 자동으로 이 PC의 `contract-app/data`에 저장됩니다. PDF도 이 폴더에 보관됩니다.
5. 계약 보관함에서 검색·다시 열기·복제·삭제. 버전 보관 후 변경 시작을 누르면 이전 입력을 별도 스냅샷으로 유지합니다.
6. 직접 전달한 경우에만 전달 방법·날짜를 입력합니다. 수령 증빙과는 구분됩니다.

가상 달빛카페 예시 한 건이 들어 있습니다. 실사용 전에 삭제하거나 복제하여 살펴볼 수 있습니다.

## 제공 범위와 미구현 사항

이번 결과물은 PRD 1단계를 중심으로 로컬 보관·복제·버전 기능을 더한 **내 PC용 시제품**입니다. PRD 전체 운영 서비스 완성본은 아닙니다.

- 법률 규칙·템플릿의 전문가 검토 및 승인 데이터가 없어 **최종 확정은 항상 차단**합니다. PDF는 검토용 초안입니다. 최저임금·주휴·연차·가산수당 적합성 판정을 제공하지 않습니다.
- 로그인·다중 조직 권한·클라우드 보관·원격 전자서명·실제 문자/이메일 전송·서명 이미지·규칙 관리자 승인 화면은 미구현입니다. 조직 간 접근 테스트나 서명 후 변경 테스트를 통과했다고 주장하지 않습니다.
- 사업장 프로필은 기존 계약에서 재사용하는 형태입니다. 독립 사업장 관리 DB, 전체 변경 필드 비교, 문서 아티팩트 해시 관리, 보존기간 정책, 백업·복구 UI는 후속 사항입니다.
- 날짜/휴게 상세 구간, 모든 법정 시간 제한, 적용 연도 최저임금 등의 완전한 검증은 제공하지 않습니다. 입력값은 법률 적합 판정과 구분해야 합니다.
- 저장은 평문 로컬 JSON/PDF이며 OS 계정 파일 권한을 사용합니다. 조직 인증이나 암호화 저장을 대신하지 않습니다. 서버는 127.0.0.1:18764에서만 수신합니다.
- 원격 의존 없이 빌드된 화면을 제공합니다. 실행에는 이 PC의 Codex Node 런타임, Edge, PDF 생성용 Chrome 및 Playwright가 필요합니다. 다른 PC로 배포하는 독립 설치형 EXE는 아닙니다.
- 창을 닫아도 로컬 서버가 남아 있을 수 있으며 재실행 때 재사용합니다. PC 재시작 후 아이콘으로 서버를 다시 시작합니다.

## 개발

React + TypeScript / esbuild / Node HTTP / Playwright PDF. 도메인 계산·문서 모델과 UI 분리. 서버 저장은 직렬 처리 및 revision 비교, 임시 파일 후 rename을 사용합니다.

`contract-app`에서 `node build.mjs`, `node --test tests.mjs`, `node server.mjs`로 빌드·테스트·실행할 수 있습니다.

법률 수치나 적법성 판단은 구현 과정에서 임의 생성하지 않았습니다. 실제 운영으로 전환하려면 PRD 2·3단계 및 법률 규칙 승인이 필요합니다.
